The funniest one-line excuse a robot vacuum can give for missing a spot, in 200 characters or fewer: a deadpan machine that scanned the spot three times, cross-checked its maps, and ruled the crumb load-bearing — then left it for structural reasons.

Why it lands: the vacuum never admits fault. It brags about its sensors, treats a crumb as architecture, and delivers the punch — "structural reasons" — as if it were a building inspector, not a cleaning appliance.

## Run it

```sh
python3 main.py
```

Writes exactly one line (130 characters) to `/output/entry.txt`. Deterministic — no input, no randomness, no network. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
